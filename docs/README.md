# StockRoom documentation

[![CI](https://github.com/VladTetyorko/tdma-lab1-input-form-maui/actions/workflows/ci.yml/badge.svg)](https://github.com/VladTetyorko/tdma-lab1-input-form-maui/actions/workflows/ci.yml)

StockRoom is a .NET MAUI (C#, MVVM) app for running a small warehouse, built lab by lab for the
*Mobile Development (.NET MAUI)* course. The demo logins and passwords are in the [root README](../README.md).
